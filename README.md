# Barline: An app built by a musician, for musicians :notes:

## Description
Barline is an app for musicians, to be able to track their progress. Growing up I always found it hard to track my progress, especially when I got to the later grades. It was hard to keep track of all the pieces I was doing, how I was at them and, overall it was just pretty annoying.
So many years later, I have created an app to fix the problem that I once had, and so many others have now.

This app is being developed in Android Studio, and my primary language for this is Kotlin. Along with this, I am using Firebase for account services and verification. This makes the process much more secure for the user, and nothing will be able to be accessed by anyone else.
